# 📚 Snap2Study

> Turn a photo of a question into a frictionless study experience.

Snap2Study is a simple study tool designed to remove the repetitive steps students go through when studying from textbooks, notes, or question papers.

Instead of manually typing a question into a search engine or AI tool, students can simply upload a photo and get a clean, editable question with useful study actions.

## ✨ Features

- 📸 Upload a photo of a question
- 🔍 Extract text from the image using OCR
- ✏️ Edit and correct the extracted question
- 🧠 Get an explanation of the question
- ⚡ Get a step-by-step solution
- 📝 Generate short revision notes
- 🔄 Generate similar practice questions
- 📱 Responsive and easy-to-use interface

## 🎯 Why Snap2Study?

Studying often involves unnecessary steps:

**Take photo → manually type question → search → copy → understand → make notes**

Snap2Study aims to make this:

**Take photo → Snap2Study → Study**

The goal is not to replace learning, but to remove the friction between a student and the learning material.
